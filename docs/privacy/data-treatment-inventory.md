## Regras mínimas de publicação

- Nunca publicar CPF, documento, contato, endereço, escola, responsável, dados médicos, credenciais, dados financeiros ou localização residencial/rotineira precisa.
- Para menores, usar nome público e categoria; imagem, biografia e depoimento exigem autorização específica e registrável.
- Imports “oficiais” devem aparecer no painel administrativo, possuir procedência e permitir correção sem alterar o registro original silenciosamente.
- Exportações devem respeitar função, finalidade e minimização; dados sensíveis não devem integrar CSV genérico.
